满税前3000欧元，可获得额外2张福卡

满税前8000欧元，可获得额外5张福卡

满税前18000欧元，可获得额外10张福卡

订单福卡获取规则

在活动有效订单时间内

单张有效订单每满税前1000欧元即可获得1张5位数的随机数字福卡

累积金额不可获得额外福卡

（示例：如同一客户在活动有效订单时间内连续订单，首次订单1800欧（获得1张福卡），二次订单1200欧（获得1张福卡），以单张订单计算）

拆分订单，合并订单等均以单张发票金额为准

同一CIF号客户的所有订单发票统一计算，以单张发票为准

如订单取消，退货，发票退款，与其关联的订单发票产生的福卡即为无效福卡

订单与发票金额不一致时，以最终发票金额为准

福卡与单张发票，CIF号唯一绑定

活动参与主体与奖品归属

1. 本活动以客户税务识别号码（CIF/NIF）作为主要身份识别依据。每个符合条件的客户主体享有相应的福卡参与资格。

2. 同一税务主体下的多个门店、客户账号或员工，不因账号数量增加而重复获得按客户身份发放的奖励。

3. 中奖资格原则上归属于获得中奖福卡的客户主体。企业客户可指定一名经合法授权的自然人办理领奖手续，但该授权不当然改变奖品所有权或税务归属。

4. 中奖者不得私自出售、转让中奖资格，亦不得要求组织方将奖品交付给未经核验的第三方。

5. 如中奖客户为法人企业，奖品登记至企业还是自然人名下，应在领奖前通过书面文件明确，并依法处理可能涉及的税务及财产转移事项。

福卡有效性及订单异常处理

1. 福卡仅在对应订单满足活动要求、付款完成且有效发票生成后正式生效。

2. 订单发生全部退款、取消或发票作废，导致不再满足参与条件的，相关福卡可按已公布规则失效。

3. 订单发生部分退款、金额调整或贷项发票时，应重新核算符合条件的税前有效交易金额。

4. 因系统延迟导致福卡未及时显示，但客户能够证明其在规定时间内完成有效交易的，组织方应核查并作出合理处理。

5. 不得仅因系统显示错误而直接剥夺客户依法及依活动条款取得的有效参与资格

中奖资格复核

1. 所有抽奖结果均须经过中奖资格复核后正式确认。

2. 复核内容包括福卡有效性、客户身份、订单及付款记录、是否存在重复中奖限制，以及奖品领取所需的法定条件。

3. 组织方可以要求中奖者提供必要的身份证明、企业授权文件、税务资料及联系方式。

4. 如发现虚假资料、冒用身份、伪造交易或其他足以影响中奖资格的违规行为，组织方有权在充分核实后取消相关资格。

5. 对存在争议的资格核验结果，中奖者可通过活动指定渠道提出申诉。
