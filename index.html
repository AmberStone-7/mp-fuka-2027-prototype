2026-2027 中汇新年福卡 · 交互原型

按 2026 线上系统重做：H5 沿用深红金活动页（单页 + 底部 5 tab），后台沿用 Ant Design 浅色后台（白侧栏 + 蓝主按钮 + 筛选/表格/分页/弹窗）。去年已满足的功能保留，今年只做增量。

全量 V1.0 基于 PRD V2.9 参考 2026 线上系统

前台 H5 单页 + 底部 5 tab；二级页带「← 返回」；右下角 ✎ 可看说明与演示

H5-01 · 首页 本期上线 H5 首页（4 个入口） 按 2027 设计图：红色 MAIN★PAPER + 2027 福卡主视觉 + 领取福卡 / 查询福卡·中奖 / 活动奖项 / 活动细则与赞助。 打开页面 → H5-02 · 活动查询 本期上线 活动查询（含中奖查询） 输入发票号 + 税号（CIF）验证后返回名下全部福卡（含其他发票）+ 我的邀请码；中奖状态直接显示在福卡上。 打开页面 → H5-03 · 领取福卡 本期上线 领取福卡（邀请有礼） CIF + 邀请码领取；成功 / 待达标 / 已领取 / 统一错误 / 邀请人上限。 打开页面 → H5-04 · 礼品展示 本期上线 礼品展示 五档奖品：图片 + 名额 + 匹配方式 + 领奖说明；口径待市场部 11/5 确认。 打开页面 → H5-05 · 中奖公示 本期上线 中奖公示 脱敏名单（奖项 + CIF 打码 + 奖品），按奖项筛选，公示期提示。 打开页面 → H5-09 · V2.0 改动说明 新增 V2.0 本次改动说明 原型改动记录：已完成项与待改项；左下角红色标记表示已改页面。 打开页面 → H5-08 · 福卡样式总览 演示 福卡样式总览（演示） 待开奖 / 1–5 等奖 / 未中奖 / 已失效 / 邀请福卡样式 + 字段来源说明。 打开页面 → H5-06 · 礼品领取登记 本期上线 礼品领取登记 一至四等奖扫码加对应微信登记；五等奖联系业务员备注「新年五等奖」，随单发放。 打开页面 → H5-07 · 活动细则与赞助 本期上线 活动细则与赞助 活动时间 / 获卡方式 / 新客与邀请 / 福卡类型 / 规则全文（折叠）+ 赞助商（占位）。 打开页面 →

后台 6 个模块（V1.4 已删除新客资格 / 退单与失效 / 用户端首页）；「✎ 原型说明」含接口与开发规格

ADM-01 · 福卡管理 本期上线 福卡管理 沿用去年列（账套/客户/手机号/业务员/发票/金额/状态/备注/时间）+ 来源标签、号码池余量、失效。 打开页面 → ADM-02 · 邀请码管理 本期上线 邀请码管理 批量生成 / 停用恢复 / 使用记录（pending-success-expired）/ 官方码配置。 打开页面 → ADM-03 · 抽奖管理 本期上线 抽奖管理 快照 → 录入号码 → 预览命中 → 复核 → 发布 → 撤回；超额截取 / 不足补抽 / 空开奖。 打开页面 → ADM-04 · 奖品管理 本期上线 奖品管理 沿用去年列表 + 编辑弹窗；补名额、匹配位数、二选一与名额校验。 打开页面 → ADM-05 · 中奖记录 部分上线 中奖记录 沿用去年列与批量编辑；新增二等奖登记信息、五等奖「随单发放（不追踪）」。 打开页面 → ADM-08 · 直播配置 新增 直播配置（V2.7） 1/10、2/10、3/10 三场直播日期、链接、预告图。 打开页面 → ADM-06 · 邮件日志 部分上线 邮件日志 沿用去年日志与重发；补 6 类模板（本期 2 类）、失败原因、待人工联系清单。 打开页面 →
怎么用：每个页面右下角 ✎ 打开「原型说明」，可看对应 FR/AC、发布范围、状态与异常、待确认项，以及演示按钮（切成功/失败/空态等）。H5 页面同时支持手机与桌面浏览器浏览；后台为 1440 桌面版。

使用与交付说明

本地打开双击本目录 `打开原型.command`，或浏览器访问 http://127.0.0.1:8899/index.html；也可直接双击 `index.html`。
数据说明全部为演示数据，不接后端；状态切换仅前端演示，刷新后恢复。
设计依据PRD V2.9 + 2026 线上系统；旧版 24 页原型已归档在 `_archive/v0.9-旧版/`。
